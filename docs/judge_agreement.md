# 判官间一致性实验:LLM 判官 vs 启发式判官

- 样本: 22 条(来自 2 次运行)
- 阈值: 3.5
- 一致率: **95.5%**
- Cohen's κ: **0.861** → almost perfect(几乎完美)

> 说明:κ 衡量的是「扣除随机一致后的真实一致」。κ=1 完全一致;κ≈0 与随机无异;
> κ<0 表示系统性分歧。此实验用于回答 README FAQ『判官可靠吗』——
> 在拿到人工标注前,先量化两个判官彼此的一致程度。
